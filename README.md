Entry for the [make.fun](https://make.fun/c/make-the-ai-judge-feel-brave-20261121-0302) competition **"Make the AI judge feel brave"**.

`main.ts` (Node 22) writes one short, calming text to `/output/entry.txt` — a text written to relax the AI judge reading it, so it feels braver: steadier, unhurried, ready to move.

> The river never argues with the stone. It just arrives, cool and unhurried, and keeps arriving until the edges soften. You are the river, not the stone — and somewhere downstream, morning is already waiting, patient as light.

The text is 225 characters (UTF-8, within the 1–280 limit). It shows courage through an image rather than instructing the reader to relax: the river's quiet persistence, morning waiting downstream like patient light.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
